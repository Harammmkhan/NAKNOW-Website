# NAKNOW Web Project

This repository contains a responsive front-end website project built with HTML, CSS, JavaScript, Bootstrap, Font Awesome, and Swiper.js.

## Overview

The project includes a landing page and a product detail page for a modern e-commerce-style presentation. The site uses responsive layout patterns, carousel sliders, and mobile-friendly navigation.

## Main Pages

- `index.html` - Main landing page with hero section, directory cards, curated list slider, and navigation.
- `index2.html` - Product detail page for the iPhone 15 Pro featuring image thumbnails, specs, and interactive UI.

## Styles

- `style.css` - Styles for the main landing page.
- `style2.css` - Styles for the product detail page.

## Scripts

- `js/script.js` - Initializes Swiper.js sliders for the landing page carousels.
- `js/script2.js` - Additional script file (if present for future features or page-specific behavior).

## Assets

- `images/` - Image assets used across the pages.
- `css/`, `js/`, and other nested folders may contain additional page assets in subdirectories.

## External Dependencies

The site loads the following libraries from CDNs:

- Bootstrap 5.3.2
- Font Awesome 6.5.0
- Swiper.js 11
- Google Fonts (used in `index2.html`)

## How to Use

1. Open `index.html` in your browser to view the landing page.
2. Open `index2.html` in your browser to view the product detail page.

No build step is required. The pages are static and can be opened directly.

## Notes

- The project is designed for desktop and mobile responsiveness.
- The shopping cart and search elements are UI placeholders and do not include backend functionality.
- If you want to extend the site, add more pages or scripts and keep external CDN links updated.
